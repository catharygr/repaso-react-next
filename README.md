## Repaso de React con Nextjs

Este proyecto ha sido desarrollado para repasar y consolidar los conocimientos adquiridos en React y Next.js. A lo largo del desarrollo, he implementado diversas funcionalidades y componentes que reflejan mis habilidades y proyectos personales.

## Descripción del Proyecto

El proyecto consiste en una aplicación web que muestra mi portafolio personal. A continuación, se detallan las principales características y componentes implementados:

### Header con Menú de Hamburguesa

- Accesibilidad: El menú de hamburguesa ha sido diseñado siguiendo prácticas de accesibilidad para asegurar que todos los usuarios puedan navegar fácilmente por el sitio.

### Carousel de Proyectos

- Proyectos Personales: Un carrusel interactivo donde se comparten todos mis proyectos personales junto con su información relevante.

### Tarjetas de Proyectos

- Visualización de Proyectos: Tarjetas que muestran de manera detallada cada uno de mis proyectos, proporcionando una vista rápida y clara de cada uno.

### Habilidades

- Descripción de Habilidades: Un componente dedicado a describir mis habilidades y competencias en el desarrollo web.

### Mapas de Ubicación

- Ubicación: Un componente que muestra mapas interactivos para localizar mis proyectos o ubicaciones relevantes.

### Formulario de Contacto

- Formulario Controlado: Un formulario controlado que permite a los usuarios ponerse en contacto conmigo de manera sencilla.

### Footer

- Enlaces a Portafolio: El footer incluye enlaces a mi portafolio y otras redes sociales, facilitando el acceso a más información sobre mis trabajos y contacto.

## Rutas y Navegación

- Next.js: He aprovechado las capacidades de enrutamiento de Next.js para crear una navegación fluida y eficiente entre las diferentes secciones de la aplicación.

## Tecnologías Utilizadas

- React: Para la creación de componentes interactivos y reutilizables.
- Next.js: Para el enrutamiento y la optimización del rendimiento del sitio.
- CSS Modules: Para el estilo de los componentes de manera modular y aislada.
